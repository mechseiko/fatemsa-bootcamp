# Beginner Comments

## Goal
Every file should be readable by someone who has never coded, while it is shown on a projector.

## Instructions
1. Start each file with a short header comment: what it teaches and which session it belongs to.
2. Comment in a teacher's voice, for example: `THIS IS A <p> TAG: it holds a paragraph of text.`
3. Put a clear banner comment above each section.
4. Add a few `TRY THIS (live): ...` comments suggesting a quick edit to show on screen.
5. Prefer short files, plain names and simple code. No one-liners.

## Constraints
- Do not use advanced patterns without a comment explaining them.
- Do not add libraries that the lesson does not need.
