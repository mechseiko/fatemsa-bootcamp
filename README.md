# FATEMSA Bootcamp 2026 - Live Demo Codebase

Teaching codebase for the Web and Software Dev crash course (6 weeks, 12 sessions).

## Requirements
Node.js (LTS) and Git.

## Run each folder
- **01, 02, 03:** open the root `index.html` with the IDE's live preview or a Live Server extension. No build step.
- **react:** `cd react`, then `npm install`, then `npm run dev`, and open the localhost link.

## Folder to session map
| Folder | Sessions |
|---|---|
| html | 2 |
| css | 2 |
| js | 3, 4 |
| react | 7, 8 |
| git-deploy | 9, 10 |
| .agents/skills | 6 (agent skills demo) |
Sessions 1, 5, 11 and 12 use slides and live prompting rather than a folder.
